# Cold-Start Benchmark Report (T61)

> Generated by `buff bench-cold-start`. This file is created on first run
> and appended-to on subsequent runs (each row is one execution of the
> benchmark).

## Methodology

1. The inline minimal fixture
   ```buff
   func main():
       print("hello")
   ```
   is compiled to a native binary via the Buff pipeline → `rustc`.
2. The binary is spawned `RUN_COUNT + WARMUP_COUNT` times
   (default `10 + 1 = 11`). For each run, the wall-clock elapsed from
   `Command::spawn` to the first byte read from the child's stdout pipe
   is recorded.
3. The warm-up run is discarded (it primes the OS file cache; without
   the discard the median would be skewed upward by the binary's
   on-disk image load).
4. Min, median, max are computed over the remaining `RUN_COUNT` samples.
5. The result row is appended to the table below.

The measurement captures **process spawn + Rust runtime init + the user
program's prologue up to the first `print` call**. It does NOT include
the time to compile the `.buff` source — that is measured separately by
`buff bench-compile` (T55).

## Acceptance target

**Median cold-start < 50 ms** (matching bare Rust).

Buff transpiles `.buff` → Rust → native binary via `rustc`/LLVM. The
generated binary has no GC, no interpreter, no JVM — it is a static
native binary with the same process model as bare Rust. The cold-start
target is therefore "within sampling noise of an equivalent bare-Rust
`fn main() { println!("hello"); }` binary".

## Cross-language reference

These numbers are NOT measured by `buff bench-cold-start` — they are
representative ranges drawn from published third-party cold-start
benchmarks (AWS Lambda + Cloudflare Workers). They are documented here
so the Buff number has context. Reproducing them locally requires the
corresponding toolchains.

| Language | AWS Lambda cold-start (ms) | Cloudflare Workers cold-start (ms) | Notes |
|---|---|---|---|
| **Buff** | (measured locally — see table below) | (same) | Transpiles to native Rust; same binary shape. |
| **Rust** | 1 – 10 | 0 – 5 | Native binary, no runtime. Buff matches this. |
| **Go** | 30 – 150 | 5 – 20 | Go runtime init (scheduler + GC bootstrap). |
| **Java (GraalVM Native)** | 5 – 30 | 5 – 15 | Ahead-of-time compiled; JVM-mode is far slower (1 – 5 s). |
| **Java (JVM)** | 1 000 – 5 000 | n/a (Workers doesn't run JVMs) | JVM warmup dominates. |
| **Python** | 200 – 800 | 5 – 20 (Pyodide WASM) | Interpreter init; CPython startup. |
| **Node.js** | 100 – 400 | 5 – 20 | V8 init. |

Source ranges: see published AWS Lambda cold-start benchmarks
(Cloudflare, Dashbird, Thundra, NewRelic blog posts 2021-2024). Exact
numbers vary by memory tier + package size; the ranges above are the
typical cold-start distribution for the "hello world" minimal program.
