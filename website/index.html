Hello, world

Rust Verbose ceremony 
fn main() {
    println!("Olá, Buff!");
}
Buff Indentation-based 
func main():
    print("Olá, Buff!")
Why easier

No braces, no semicolons. Indentation defines blocks. func replaces fn, print is a built-in prelude function. One less concept to learn.

Borrow-checker fights

Rust Ownership headaches 
fn process(data: &Vec<i64>) {
    let sum: i64 = data.iter().sum();
    let avg = sum / data.len() as i64;
    println!("avg: {avg}");
}
Buff No references, no pain 
func process(data: Vector<Int>):
    let sum = data.iter().sum()
    let avg = sum / data.len()
    print("avg: {avg}")
Why easier

No & references. No as i64 casts for simple integer math. The transpiler owns data and emits Arc or clones where needed. You never see a lifetime.

Pattern matching

Rust Match with braces 
fn classify(n: i64) {
    let label = match n {
        0 => "zero",
        1 => "one",
        _ => "other",
    };
    println!("{label}");
}
Buff Clean one-liners 
func classify(n: Int):
    match n { 0 => print("zero"), 1 => print("one"), _ => print("other") }
Why easier

Compact match on a single line when arms are simple. No variable binding boilerplate. The _ catch-all works the same as Rust's.

Error handling

Rust Boilerplate returns 
fn half(n: i64) -> Result<i64, Box<dyn Error>> {
    if n < 2 {
        return Err("input too small".into());
    }
    Ok(n / 2)
}

fn main() {
    match half(10) {
        Ok(v) => println!("{v}"),
        Err(_) => println!("err"),
    }
}
Buff Ergonomic Result 
func half(n: Int) -> Result<Int, Error>:
    if n < 2:
        return Error("input too small")
    return Ok(n / 2)

func main():
    let result = half(10)
    match result { Ok(v) => print(v), Err(_) => print(0) }
Why easier

No Box<dyn Error>. No .into(). The builtin Error("msg") constructor maps to Rust's Err(Error::new(...)). The ? operator works identically to Rust for propagation.

Async without the coloring problem

Rust Function coloring 
async fn fetch_value() -> i64 {
    42
}

async fn pipeline() -> i64 {
    fetch_value().await
}

#[tokio::main]
async fn main() {
    let value = pipeline().await;
    println!("{value}");

    let handle = tokio::spawn(async move {
        fetch_value().await
    });
    let answer = handle.await.unwrap();
    println!("{answer}");
}
Buff No await keyword 
async func fetch_value() -> Int:
    return 42

func pipeline() -> Int:
    return fetch_value()

func main():
    let value = pipeline()
    print(value)
    let task = spawn fetch_value()
    let answer = task.result()
    print(answer)
Why easier

No .await keyword. Async propagates automatically through the call graph. spawn creates tasks, .result() replaces .await. No #[tokio::main], no function coloring.

Closures and collections

Rust Verbose closures 
fn main() {
    let doubled: Vec<i64> = vec![1, 2, 3, 4, 5]
        .iter()
        .map(|x| x * 2)
        .collect();
    println!("{}", doubled[4]);

    let stacked: Vec<i64> = vec![1, 2, 3]
        .into_iter()
        .map(|y| y * 2)
        .map(|y| y + 1)
        .collect();
    println!("{}", stacked[0]);
}
Buff Chained and clean 
func main():
    let doubled = [1, 2, 3, 4, 5].map({ x => x * 2 })
    print(doubled[4])
    let stacked = [1, 2, 3].map({ x => x * 2 }).map({ y => y + 1 })
    print(stacked[0])
Why easier

No .iter(), no .collect(), no type annotations on the binding. Lambdas use { x => body } syntax. Chains read left-to-right naturally.
