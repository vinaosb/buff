# Variables in Buff

In Buff, you declare variables with `let`. The compiler infers the type automatically.

```buff
let name = "Buff"
let year = 2026
```

## Your task

The exercise file `variables1.buff` has a `// TODO:` marker. Replace `"TODO"` with `"Buff"` (or your name) inside the `print` call, then remove the TODO comment line.

Run `bufflings verify variables1` to check your solution.
