E1303

`block()` inside an async function can deadlock

block() was called inside an async func. block_on parks the current worker thread, which can prevent any future scheduled on the same worker from running — a deadlock. Codegen still emits the call (so you can see what you wrote), but treats it as a warning.

Fix: remove block() and let the async fn return the future directly, or restructure so the blocking work happens in a non-async function.

Severity: Warning
Phase: Code generation
