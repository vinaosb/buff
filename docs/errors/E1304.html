E1304

codegen cannot lower a comptime value to Rust

Codegen could not splice a comptime-evaluated value into the generated Rust source. The comptime interpreter produced a value of a shape the lowering pass does not yet handle (e.g. a nested array of structs, or a value of a user-defined type without a const constructor).

Fix: simplify the comptime expression so its result is a primitive literal or a flat array of primitives.

Severity: Error
Phase: Code generation
Stability: this code is stable across releases — it will never be renumbered or reused. See §19 of the conventions doc for the full policy.
