E1404

no GPU adapter is available on this host

No GPU adapter is available on this host. wgpu::Instance::request_adapter returned None for every backend (Vulkan/Metal/DX12/WebGPU). The runtime treats this as a soft failure — every @prefer(gpu) hint falls back to CPU automatically.

This error surfaces only when the user EXPLICITLY required a GPU (e.g. a library that refuses to run without one). Fix: install a GPU, or use the CPU path.

This is NOT a bug — it is the runtime correctly reporting host capability.

Severity: Error
Phase: Other
Stability: this code is stable across releases — it will never be renumbered or reused. See §19 of the conventions doc for the full policy.
