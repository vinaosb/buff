E1506

branch can never execute (dead code)

A branch of an if, match, or for can never execute because its condition is statically known to be false. Common shapes: if false, match x { 1 if false => … }, or a for over an empty literal range.

Distinct from E1504 (syntactically unreachable). Fix: delete the branch, or adjust the condition so the analyzer can prove it might be true.
