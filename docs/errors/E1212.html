E1212

reflection beyond type info is not allowed at comptime

A comptime { ... } block attempted reflection beyond type-level queries. Inspecting field layouts, calling methods by string name, or walking struct definitions at runtime is not allowed at comptime.

Fix: limit comptime code to type-level queries (Type.of(x), Type.fields(T)) and ordinary value computation.

Severity: Error
Phase: Type-checking
Stability: this code is stable across releases — it will never be renumbered or reused. See §19 of the conventions doc for the full policy.
