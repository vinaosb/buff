E1002

unterminated string literal

A string literal ("...") or char literal ('...') was opened but never closed before the end of the line or the end of the file. String literals in Buff cannot span lines unless you interpolate ("{expr}") or escape (\n) the newline.

Fix: add the missing closing quote on the same line, or split the literal across several literals joined by interpolation.

Severity: Error
Phase: Lexing
Stability: this code is stable across releases — it will never be renumbered or reused. See §19 of the conventions doc for the full policy.
