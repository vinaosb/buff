E1014

unterminated interpolation in string literal

A { opening a string interpolation was never closed with } before the end of the line or end of input. String interpolations cannot span lines.

Fix: add the closing } on the same line, or break the expression out into a let binding before the string.

Severity: Error
Phase: Lexing
Stability: this code is stable across releases — it will never be renumbered or reused. See §19 of the conventions doc for the full policy.
