E1509

`if`/`else` branches produce identical values

The two branches of an if/else expression produce byte-identical values, making the conditional redundant. This is almost always a copy-paste typo — the user duplicated one branch to start writing the other, then forgot to change the duplicated body.

Fix: delete the redundant branch (or merge the two), or change the duplicated body to actually differ.

Severity: Error
Phase: Other
Stability: this code is stable across releases — it will never be renumbered or reused. See §19 of the conventions doc for the full policy.
