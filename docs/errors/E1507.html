E1507

`let` binding shadows an outer binding

A let binding shadows an outer binding of the same name. Buff allows shadowing (it's idiomatic for let x = parse(s) followed by let x = x.normalize()), but accidental shadowing is a common source of bugs.

The warning names both bindings' locations so you can confirm the shadowing is intentional. Fix: rename the inner binding, or — if intentional — add a # noqa comment once that directive is implemented (tracked as T48b).

Severity: Error
Phase: Other
