E1202

binary operator applied to incompatible types

A binary operator (+, -, *, /, <, ==, and, or, |, &, ^, …) was applied to operands whose types it does not accept. For example, Int + String, or Int < Bool.

The message names the two operand types. Fix: cast one side explicitly, or rethink the operation — Buff's numerics follow Rust's, so integer division and unsigned/signed mix are common surprises.

Severity: Error
Phase: Type-checking
