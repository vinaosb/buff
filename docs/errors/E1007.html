E1007

unterminated regex literal

A regex literal /.../ was opened but the closing / was not found before end of line or end of input. Regex literals in Buff cannot span lines.

Fix: add the closing / on the same line, or break a long pattern into a string + Regex.compile call.

Severity: Error
Phase: Lexing
Stability: this code is stable across releases — it will never be renumbered or reused. See §19 of the conventions doc for the full policy.
