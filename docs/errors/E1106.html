E1106

expected an identifier

An import, export, attribute, let, func, or similar declaration requires a name (identifier) at the cursor, but none was found. Usually this means a typo, a stray keyword in name position, or end of input.

Fix: write the identifier the construct expects.

Severity: Error
Phase: Parsing
