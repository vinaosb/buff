## What was built

Four prelude-implicit system modules, all lowering to Rust via `syn`/`quote`/`prettyplease` (NO raw-string codegen):

| Module / fn | Surface | Generated Rust | extern crate |
|---|---|---|---|
| `Args.list()` | assoc fn, namespace `Args` | `std::env::args().collect::<Vec<String>>()` | — (std only) |
| `Args.get(i)` | assoc fn, namespace `Args` | `std::env::args().nth(i).unwrap_or_default()` | — (std only) |
| `Env.get("KEY")` | assoc fn, namespace `Env` | `std::env::var(k).ok()` | — (std only) |
| `Env.set("KEY","v")` | assoc fn, namespace `Env` | `std::env::set_var(k, v)` | — (std only) |
| `Env.has("KEY")` | assoc fn, namespace `Env` | `std::env::var(k).is_ok()` | — (std only) |
| `input()` | free fn (0 or 1 args) | block: read_line + `.trim_end().to_string()` | — (std only) |
| `input(prompt)` | free fn with prompt | block: `print!(prompt)` + `flush()` + read + trim | — (std only) |
| `sleep(Duration.seconds(N))` | free fn | `tokio::time::sleep(std::time::Duration::from_secs(N)).await` | **tokio** |
| `sleep(N)` (plain int) | free fn | `tokio::time::sleep(std::time::Duration::from_secs(N)).await` | **tokio** |
| `sleep(expr)` | free fn passthrough | `tokio::time::sleep(expr).await` | **tokio** |

## Why this design

1. **Args + Env are namespace-only** (mirroring Log/Toml/Math/Random/Strings from T124c–f). They have no runtime value; only their assoc fns are callable. `buff_type()→Type::Void`, `is_namespace_only()→true`.

2. **input + sleep are free fns** (mirroring `read_line`/`args`/`env`/`exit` from T99). The existing `MethodCall` (for Args/Env) and `FuncCall` (for input/sleep) AST shapes handle them — no new AST node, no new keyword (the 25-keyword freeze holds).

3. **Consolidated `Get` variant** for `Args.get` and `Env.get` (mirrors `Parse` shared across DateTime/Date/Toml). This avoids duplicate-name complications in the `PreludeAssocFn` enum and the no-duplicates invariant test. The dispatch is on the (type, method) pair, exactly like `(DateTime, Parse)` vs `(Date, Parse)` vs `(Toml, Parse)`.

4. **`assoc_fn_lookup` rewritten** to scan ALL variants matching a name and return the first whose (type, method) pair validates. The original `find(|f| f.name() == method)` returned the FIRST matching variant unconditionally, which broke same-named variants across distinct types. The new scan-with-validation is correct for any number of same-named variants.

5. **`program_uses_tokio` walker is NARROW** (per T124f gotcha where chrono was originally over-broad). It flags ONLY a `FuncCall` whose callee is the bare Ident `sleep` — NOT every async fn, NOT every `tokio::*` path fragment. Same conservative strategy as the rand walker.

6. **Sleep duration handling** detects the AST shape `Duration.seconds(N)` (Buff's chrono-flavored ctor) and rewrites it to `std::time::Duration::from_secs(N)` so the sleep path is chrono-independent (`tokio::time::sleep` requires `std::time::Duration`, NOT `chrono::TimeDelta`). Plain Int args are treated as seconds (per the task spec's "plain int-seconds form" fallback). Other arg shapes pass through unchanged (user responsibility — useful for `sleep(my_duration_var)`).

7. **`set_var` is `unsafe` in Rust 2024** but Buff emits Rust 2021, so the call is safe today. A future edition bump will need an `unsafe { ... }` wrapper — tracked in `decisions.md`.

8. **Codegen-only linking boundary** (consistent with chrono/regex/toml/rand): single-file `buff run` rustc path does NOT link tokio; the `extern_crates` set is the verifiable contract. Cargo-project wiring is deferred. End-to-end-link limitation noted in `issues.md`.
