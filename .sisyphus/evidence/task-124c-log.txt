## Sample transpiled output

### Buff source (canonical acceptance example)

```buff
func main() {
    Log.info("hello", count: 42)
}
```

### Generated Rust (snapshot-verified, byte-identical across runs)

```rust
fn main() {
    {
        let __buff_log_filter = tracing_subscriber::EnvFilter::try_from_env("BUFF_LOG")
            .unwrap_or_else(|_| tracing_subscriber::EnvFilter::new("info"));
        let _ = if cfg!(debug_assertions) {
            tracing_subscriber::fmt().with_env_filter(__buff_log_filter).try_init()
        } else {
            tracing_subscriber::fmt()
                .with_env_filter(__buff_log_filter)
                .json()
                .try_init()
        };
    }
    tracing::info!(count = 42, "hello");
}
```

### Plain `Log.info("hi")` (no fields)

```rust
tracing::info!("hi");
```

### Multiple structured fields preserve source order

`Log.info("msg", a: 1, b: 2)` →

```rust
tracing::info!(a = 1, b = 2, "msg");
```

### `Log.error("oops")`

```rust
tracing::error!("oops");
```

## extern_crates recorded

When a program uses `Log`, `codegen.extern_crates()` returns:

```text
{ "tracing", "tracing-subscriber" }
```

Both crates are recorded in the `BTreeSet` (deterministic iteration order)
via the `program_uses_tracing(decls)` helper. The codegen crate does NOT
depend on tracing itself — it's only emitted in generated code. Single-file
`buff run` rustc path does NOT link them; cargo-project wiring is deferred
(same codegen-only linking boundary as chrono/tokio from T124b).

## Key design decisions

1. **`PreludeType::Log` added as a namespace-only variant.** `Log` is
   never a runtime value — only its assoc fns are callable. `buff_type()`
   returns `Type::Void`. The new `is_namespace_only()` predicate lets the
   test suite skip the datetime-only `is_prelude_datetime` check for Log.
2. **Source-order field emission** for `tracing::<level>!(k1 = v1, k2 = v2, "msg")`.
   Tracing itself preserves insertion order, so source order matches
   user intent.
3. **`try_init()` not `init()`** in generated subscriber init — never
   panics on duplicate install (matches Buff's "no panicking generated
   code" stance).
4. **`cfg!(debug_assertions)` branch** for dev (pretty to stderr) vs
   release (JSON to stdout). Single filter built once outside the
   if/else, moved into the executing branch (sound in Rust's branch
   semantics).
5. **`Log` calls bypass the T105 named-arg resolution** in
   `lower_expr`'s `MethodCall` arm. The standard resolution drops arg
   names (passes only values), but Log needs the names for tracing
   fields. Intercepted BEFORE the resolution.
6. **Subscriber init emitted only in `main`** — helper fns using `Log`
   don't pay the init cost. The init is the FIRST statement in `main`'s
   body (wrapped in a `{ ... }` block to scope the filter binding).
