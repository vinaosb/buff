Action Behavior
----------------
1. Reads buff-version and buffup-version inputs
2. Sets BUFF_HOME env var to $HOME/.buff
3. Restores $HOME/.buff/versions/ from cache (key: ${{ runner.os }}-${{ runner.arch }}-buff-${{ version }})
4. If cache miss:
   a. Downloads + runs buffup install script (curl|sh on Unix, PowerShell on Windows)
   b. Runs `buffup install <version>`
   c. Runs `buffup default <version>`
   d. Saves $HOME/.buff/versions/ to cache
5. Appends $HOME/.buff/bin to GITHUB_PATH
6. On failure: core.setFailed() + exit code 1

Platform Support: linux, darwin, win32 (unsupported platforms logged as error)
